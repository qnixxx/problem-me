WHAT PROBLEM.ME DOES_

This version serves informational pages, diagrams and original capybara illustrations. It does not offer sign-up, visitor submissions, comments, cloud storage, personalized analytics or advertising. Reading the content does not require application cookies, localStorage, sessionStorage or IndexedDB.

The small terminal boot animation runs in memory only and does not retain or transmit what you read. There is no AI model processing your page activity.

HOSTING AND NETWORK REQUESTS_

Problem.me is published using GitHub Pages. Every visit still involves standard browser requests for pages and local assets. GitHub says it logs visitors' IP addresses for security, including unauthenticated GitHub Pages visits. GitHub describes its own controller responsibilities, legal bases, retention criteria, international transfers, recipients and privacy-rights procedures in its published privacy information.

Read GitHub's GitHub Pages data-collection information and GitHub Privacy Statement. Following these links opens a third-party website.

No visitor-entered problem descriptions are sent to GitHub, because this read-only site does not collect them.

PREVIOUSLY SAVED INVESTIGATIONS_

Earlier versions of Problem.me offered optional browser-local investigation saves. The read-only release no longer opens, edits, exports or deletes those records. Removing the old workspaces does not automatically erase data stored in a visitor's browser profile. If you used the old site, you can clear its site data through your browser settings; note that this also removes other data stored for this domain.

The previous code is retained in the project's Git history for rollback. This does not mean the site currently processes or uploads your earlier saved investigations.

WHAT THIS NOTICE DOES AND DOES NOT MEAN_

Removing visitor input and tracking minimizes the site's privacy footprint, but standard hosting requests still exist. A static website is not automatically exempt from GDPR simply because it is a non-commercial hobby project. This page explains the current site's behavior and does not claim a legal certification or imply that hosting cannot involve personal data.
