CAPYBARA PRIVACY NOTES // v1.0.0

Last updated: 16 October 2026. problem.me is a non-commercial hobby project.

Your problemsstay yours.

problem.me is designed to work without an account or cloud investigation store. Your reasoning can stay in the browser, but “local” does not mean “magic vault.” These notes explain the boundaries.

LOCAL-FIRST_

WORK STAYS IN YOUR BROWSER

Standalone technique drafts use browser local storage. Saved Shared Investigations use IndexedDB on the current browser and device.

PRIVATE SESSION_

NO PROBLEM.ME PERSISTENCE

Private Session keeps current investigation changes in page memory instead of writing them into problem.me browser storage. Refreshing or closing can discard them.

PORTABLE FILE_

.PROBLEMME IS READABLE JSON

Exports are data files, not encrypted containers. Anyone you give the file to can read the investigation content.

NO SECRET VAULT_

DO NOT PASTE CREDENTIALS

Avoid passwords, API keys, access tokens, private keys, recovery codes or other secrets in problem descriptions and evidence notes.

WHAT “LOCAL” MEANS_

When Local Save is active, problem.me writes investigation data into storage controlled by your browser. Shared Investigations use IndexedDB; the older standalone technique workspaces use localStorage for their own drafts.

That storage belongs to the current browser profile on the current device. Clearing site data, privacy cleanup tools, browser resets or changing devices can remove it.

BROWSER STORAGE IS NOT A BACKUP. Export important investigations as .problemme files and keep those copies somewhere you trust.

STORAGE AND RETENTION_

The application does not set cookies or include advertising, analytics, tracking pixels or externally hosted fonts. It uses browser storage for saving and reopening your work, not to build visitor profiles.

  • Standalone 5 Whys, Fishbone, Pareto and Kepner–Tregoe: Local Save is on by default. These pages read an existing draft when opened and save edits and evidence notes in localStorage. Choose Private Session before entering content if you do not want those changes saved. That choice applies to the current page session; reopening a standalone page starts in Local Save again.
  • Shared Investigations: a new investigation starts in Private Session. Choosing Start Local Save enables saving to the browser's IndexedDB database named problem.me. Opening an existing saved investigation resumes Local Save. My Investigations reads this database to list your saved work.
  • Older saved files: My Investigations can migrate a compatible legacy pilot record from localStorage into IndexedDB. This happens on your device, without uploading it.
  • Living Investigation Board: the experimental board keeps changes in page memory. Use its download and open controls to keep or reopen a board file; closing or refreshing can discard unexported work.

Saved drafts and investigations have no application-set expiry. They remain until you delete or overwrite them, clear the site's browser data, or your browser removes them. Memory-only sessions are not a durable backup. Downloaded files remain wherever you save them until you remove those copies.

Local data can include your problem statement, causes, observations, evidence labels, scores, test results, titles and timestamps. Use roles or pseudonyms where possible. Other people or software with access to your browser profile or device may be able to read it.

WHAT PRIVATE SESSION MEANS_

Private Session is a problem.me storage mode. While active, current investigation changes are not persisted into problem.me local investigation storage. An older saved copy can remain untouched while you work privately.

Private Session is not the same as browser Incognito/Private Browsing and it does not make the device anonymous. Your browser, operating system, clipboard manager, screenshots, downloads or other software can still create traces outside problem.me.

HOSTING AND WHAT LEAVES THE PAGE_

The application code does not upload investigation fields or opened investigation files. Calculations, imports and exports run in your browser. There are no site accounts, cloud investigation storage, purchases or contact-email submission features.

The site is hosted on GitHub Pages. Your browser sends ordinary requests for pages and assets to the hosting infrastructure. GitHub states that it records visitors' IP addresses for security, including visits made without a GitHub account. These requests are separate from the text you enter into a workspace. Page URLs and query parameters are part of requests, so do not put sensitive information into URLs.

GitHub's Pages documentation and Privacy Statement explain its processing, legal bases, recipients, international transfers, retention criteria and rights. GitHub identifies GitHub, Inc. or GitHub B.V. as controller for processing covered by that statement. Its documentation does not specify a fixed Pages security-log retention period; this site does not promise one.

Private Session does not stop hosting requests or GitHub's security logging. Following an external link takes you to a service governed by its own privacy practices.

YOUR CHOICES_

You can inspect, edit, export and delete local investigations using the workspace controls. For a fresh session without investigation persistence, open Shared Investigations without a saved-record link and keep Private Session active.

For personal data GitHub processes, its privacy-rights instructions explain how to request access, correction or deletion and exercise other applicable rights. You can also raise a privacy complaint with your relevant data protection supervisory authority.

BEFORE YOU PASTE THAT_

Problem-solving notes can contain sensitive business, personal or operational details even when they do not contain passwords. Use the minimum detail needed to reason clearly.

  • Do not enter credentials, secrets or recovery codes.
  • Prefer roles or pseudonyms when a person’s real identity is unnecessary.
  • Keep exported files only where you intend them to be stored or shared.
  • Review a summary before copying it into email, chat or another system.
  • If the information requires regulated or organization-specific handling, follow those rules first.

DELETING LOCAL DATA_

My Investigations can delete individual saved investigations or all locally saved investigation records. Standalone technique pages also expose local-data clearing controls for their drafts.

The standalone tools’ clearing controls remove localStorage drafts; My Investigations manages the separate IndexedDB records. To remove both, clear all site data for problem.me in your browser settings. Close other problem.me tabs first to avoid an open Local Save session writing again.

Deletion from problem.me browser storage does not delete copies you already exported, printed, copied, screenshotted or backed up elsewhere.

IF AI OR CLOUD FEATURES ARRIVE LATER_

The privacy boundary should stay explicit. Any future feature that intentionally sends investigation content to a remote service should say so before transmission and should remain distinguishable from the current local-first workflow.

CAPYBARA RULE: Never make the user guess whether their problem is staying on the device.
